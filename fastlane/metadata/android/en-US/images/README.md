# Store images

Play / F-Droid expect:

| Path | Spec |
|------|------|
| `images/icon.png` | 512×512 PNG |
| `images/featureGraphic.png` | 1024×500 PNG |
| `images/phoneScreenshots/*.png` | ≥2 phone screenshots |

`icon.png` and `featureGraphic.png` are generated from the app launcher for listing scaffolding.

**Before store submit:** replace `phoneScreenshots/` with real device captures (Home, Prepare, Explore, Settings). Do not ship placeholder screenshots to Play.
